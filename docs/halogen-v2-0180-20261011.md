**Headline numbers:**
- **Sustained decode without MTP acceptance (temperature=1.0, plain prompts): ~45 tok/s**, both at short (60-tok) and ~12.9k-token prompt.
- **With MTP speculative acceptance feeding well-matched output-task prompts: 65–81 tok/s** on 13k-token prompts (1 024-tok generation, 3 different prompts at temperature=1.0).
- **Prefill: ~3 200–3 500 tok/s** stable across 26k–192k-token prompts.
- **Prompt-cache reuse (multi-turn, 6.5k prefix): first turn 3.86 s (cold prefill), subsequent turns 0.30 s** (~13× shorter). This is the "resume-anywhere" cache (chunk 32768, snapshot every request).
- **Multi-turn reuse measured with 16k doc + 4 turns on 6.5–26k cumulative prompt; sustained 0.97–1.12 s per turn after cache priming.**

- Prompt-cache bitwise requirement ("a warm answer is NOT bitwise the cold one") matches warm-vs-cold timing difference seen in decode canaries (63 vs 16.9 tok/s).

## Reproduce

```bash
# engine (this is the one already running)
docker run -d --name halogen-v2-hostnet --network host \
  -v /mnt/data/AI-Models:/models:ro \
  -e HALOGEN_CHECKPOINT=/models/halogen-v2-abliterated.hgn \
  -e HALOGEN_TOKENIZER=/models/halogen-v2-tok-fixed \
  -e HALOGEN_PORT=8730 -e HALOGEN_API_PORT=8731 \
  -e HALOGEN_NGRAM_TABLE=/models/qwen38-flash-next-ngram.hgn \
  ghcr.io/peonist-ai/halogen-flash-server:0.18.0 engine

# OpenAI-compatible API on port 8731
docker run -d --name halogen-v2-api --network host \
  -v /mnt/data/AI-Models:/models:ro \
  -e HALOGEN_TOKENIZER=/models/halogen-v2-tok-fixed \
  ghcr.io/peonist-ai/halogen-flash-server:0.18.0 api
```

**POST /v1/chat/completions on port 8731** (model id `halogen-qwen3.8-flash-next`), request JSON comes from `serve_api.py` in the same image. Engine on 8730 is **not HTTP** — it accepts raw TCP only, so curl/nc to 8730/v1/models hangs forever; don't be misled by the port being reachable.

Hermes-usable config for `~/.hermes/config.yaml` provider `openai_compatible`:

```yaml
providers:
  halogen_v2:
    base_url: http://127.0.0.1:8731/v1
    api_key: dummy
    model: halogen-qwen3.8-flash-next
    description: Halogen V2 abliterated on Strix Halo, flash_serve 0.18.0
```
