# Dahlia

Izometrická pixel-art point-and-click adventura s českým textem.

- Jeden samostatný soubor `index.html` — žádné externí assety, žádná síť.
- Plátno 360x280, `image-rendering: pixelated`, izometrická kamera 30 stupňů.
- Prolog (2026) a kapitola 1 (zahrada 2256) s klikacími hotspoty a dialogy.
- Bez fail stavů, bez časovače.

Otevři `index.html` v prohlížeči nebo hraj na GitHub Pages.
